**구현 전에 정한 것** (사용자 답)
- '1단계 없이 면접'은 1차 발표일 칸에 **'없음'** 으로 저장해요. 시트에도 '없음'으로 보여요.
- 학생이 바꿀 수 있는 칸은 5개예요: 1차 발표일 · 결과 · 누른 시각 · 수정 시각 · 수정자('학생'만).
- 면접 당일의 후기 쓰기는 **'오늘' 카드에만** 보여요. 맨 위 띠는 다음 날부터 지난 면접 후기만 보여요.

## 바뀐 것
### 학생
- **홈 맨 위 '오늘' 카드**: 그날 해당하는 줄만 보여요. 없으면 카드도 없어요. 휴대폰과 컴퓨터가 같아요.
  - 보라 점 '오늘 ○○대 1차 발표일이에요' + 학과·전형 + 작은 [합격] [불합격]
    - 합격을 누르면 '○○대 1차 합격 🎉 · 면접일 m/d · D-n · 알렸어요'
    - 불합격을 누르면 '○○대 결과를 알려 줘서 고마워요'. 다음 날부터는 안 보여요.
  - 검은 점 '오늘 ○○대 면접일이에요 · 잘하고 와요! 저녁 6시부터 후기를 쓸 수 있어요'
    - 18시부터는 '오늘 ○○대 면접, 어땠나요? [후기 쓰기]'로 바뀌어요. 다 쓰면 '후기를 남겼어요 [후기 보기]'예요.
  - 회색 점 '내일 ○○대 1차 발표 · 발표 뒤 면접 준비도 힘내요.' / '내일 ○○대 면접 · 수험표·신분증·장소를 확인해 두세요'
  - 4줄이 넘으면 3줄 + '외 n건 보기'예요.
  - ✕를 누르면 그날만 접혀요 (다음 날 다시 계산).
- **지원 대학 줄에 1차 발표일**이 생겨요.
  - 비어 있으면 '+ 1차 발표일 입력', 있으면 '1차 발표 10/2 (금) · 수정' 또는 '1단계 없음 · 수정'이에요.
  - 누르면 작은 창이 떠요: 날짜 고르기 · [저장] · [1단계 없이 면접] · [비우기] · [닫기]
  - 지난 면접은 발표일이 비어 있으면 입력 단추를 숨겨요.
  - 학생이 바꾸면 수정 시각과 수정자('학생')도 같이 남아요. 다음 정기 대조(30분) 때 시트에 들어가고, 시트 수정자 칸은 '학생'이 돼요.

### 선생님
- **'오늘' 탭의 파란 '오늘 면접' 칸 안** (컴퓨터·휴대폰 모두)
  - 큰 제목·남은 시간·모의면접 칸은 그대로 맨 위에 있어요.
  - 그 아래 **'내 담당 학생 일정'** 줄이 생겨요.
    - 순서: 대학 면접 → 1차 발표, 같은 구분 안에서는 학번순
    - 결과 알약: 아직 / 합격 hh:mm / 불합격, 18시부터 후기 / 후기 아직 / 후기 씀(누르면 후기 열림)
    - 내 담당 = 1차 담임·2차 교과·3차 위원 중 내 이름이 있는 학생이에요. 이름을 정하지 않은 관리자는 전체예요.
  - 맨 아래 **한 줄**: '● 1차 발표 충북대 · ● 면접 한국교원대   3명 ›'
    - 학교 전체 기준이에요. 3곳이 넘으면 '… 외 n곳'으로 줄여요.
    - 오늘 없고 내일만 있으면 '내일 · …'으로 보여요. 둘 다 없으면 줄이 없어요.
  - 모의면접 없이 학생 일정만 있는 날은 '오늘 잡힌 모의면접이 없어요' + 줄이에요. 학생 일정이 없는 날은 **지금 화면과 똑같아요.**
- **팝업**: 한 줄을 누르면 떠요. 컴퓨터는 가운데 창, 휴대폰은 아래에서 올라오는 시트예요.
  - 고르기: [오늘|내일] · [대학별|내 담당만]
  - 묶음: 1차 발표 / 대학 면접 → 대학 줄(인원 · 합격·불합격·아직 수 또는 학과)
    - 처음엔 내 담당 학생이 있는 대학만 펼쳐 둬요.
  - 학생 줄: 이름(누르면 학생 상세) · 학번·학과 · '내 담당' 꼬리표 · 결과 알약
  - 아래 '내일 n명 보기 ›'. 닫기는 ✕ · [닫기] · 바깥 누르기 · Esc
- **몇 초 안에 반영**: 학생이 결과를 눌러도 면접일 목록의 '바뀜' 표시는 학생이 올릴 수 없어요(규칙). 그래서 이 칸과 팝업은 오늘·내일 해당 줄만 따로 실시간으로 읽어요.
  - 읽는 것: 1차 발표일 = 오늘/내일, 면접일 = 오늘/내일, 오늘 면접 후기
- **면접일 창**(학생 상세 → 지원 대학 → 수정)
  - '1차 발표일' 칸과 '1단계 없이 면접' 체크가 생겨요.
  - 같은 대학·전형의 다른 학생이 있으면 **'같은 대학·전형의 다른 학생 n명에게도 1차 발표일 함께 넣기'** 체크가 생겨요.
  - 학생 상세 지원 대학 표에 '1차 발표' 칸(날짜·합격/불합격·1단계 없음)이 생겨요.

## 배포 순서 — 규칙 → 사이트 → Apps Script v14 (사이트와 Apps Script 는 이어서 바로)
1. **규칙**: Firebase 콘솔 → Firestore → 규칙에 `firestore.rules` 를 붙여넣고 게시해요.
   - 예전 규칙으로는 학생 결과·발표일 저장이 막혀요 (에뮬레이터로 확인).
2. **사이트**: 사이트 파일 6개(`firestore.rules` 제외, `t-announce.js` 포함)와 `apps-script/Code.gs` 를 올려요.
3. **Apps Script v14** — 사이트를 올린 뒤 **바로**
   - v13 이 도는 동안 시트에서 그 줄을 고치면, v13 이 문서를 통째로 덮어써서 학생 결과·발표일이 지워질 수 있어요.
   1. 편집기 `CONFIG` 의 `FIREBASE_API_KEY`·`FIREBASE_PROJECT_ID` 두 값을 복사해 둬요.
   2. `Code.gs` 를 전부 지우고 v14 를 붙여넣어요. `CONFIG` 두 칸에 1번 값을 넣고 저장해요.
   3. **(아침 이후에 붙여넣을 때)** 스크립트 속성에 `PUSH_ANN_DAY`·`PUSH_IVDAY_DAY` 를 오늘 날짜(예: `2026-10-27`)로 넣어요.
      - 그래야 '오늘 면접이에요'·'오늘 발표일이에요'가 낮에 늦게 가지 않아요. 저녁 6시 이후면 `PUSH_IVEVE_DAY` 도 넣어요.
      - 아침 7시 전에 붙여넣으면 넣지 않아도 돼요.
   4. 시트를 새로고침하고 메뉴 **'지금 동기화'** 를 눌러요.
      - 결과창 맨 위가 `[스크립트 v14 (2026-10-26)]` 인지 봐요.
      - '앱연동_면접일' 의 면접일 오른쪽에 **'1차 발표일'** 칸이 생겼는지 봐요.
   5. **배포 관리 → 연필 → 새 버전 → 배포** (웹 앱 URL 은 그대로)
4. **처음 넣을 값 (9장)**: 3-4 로 칸이 생긴 뒤 붙여넣어요.
