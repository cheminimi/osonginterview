# 모의면접 일정 '장소 바꾸기' (2026-10-21)

기준: GitHub main `a990918`

## 바뀐 것
- 선생님(그 일정의 담당 선생님·관리자)이 일정 상세 창의 **[장소 바꾸기]** 로 장소만 바꿀 수 있음
  - 요청 중·확정 모두 가능 (완료한 면접은 단추 없음). **수락 상태는 그대로** — 다시 [수락]을 누르지 않아도 됨
  - 장소 목록 + 기타(직접 입력), '학생에게 남길 말'(선택)
  - 같은 시간·같은 장소에 다른 일정이 있거나 그 장소를 못 쓰는 시간이면 막음 (선생님·학생 시간은 이미 정해졌으므로 다시 보지 않음)
- **'시간 변경 제안' 창에서 선생님이 장소만 바꿔도** 같은 처리 (수락 그대로 · 안내). 시간을 바꾸면 예전처럼 다시 수락
- 바꾸면 **학생에게 휴대폰 알림**: "○차 모의면접 장소가 바뀌었어요 · 날짜 교시 시간 · 예전 장소 → 새 장소"
  - **함께하는 다른 선생님**(예: 3차 두 분)에게도 알림. 바꾼 본인에게는 안 감
  - 알림은 기존 알림 대기열로 → 시트 Apps Script 가 보냄 (Apps Script 바꿀 것 없음, 밤 22~7시는 아침에)
- 변경 기록에 **'장소 변경'** 으로 남고, 시트 '면접 기록'·'면접 일정표' 탭에도 새 장소가 반영됨
- 학생 화면은 그대로: 학생이 신청·변경 제안 때 장소를 고르는 것, 학생이 바꾸면 다시 수락받는 것 모두 예전과 같음
- 장소만 바꾼 일정은 '면접 완료' 표시도 그대로 둠 (예전에는 장소를 바꿔도 완료가 풀렸음)
