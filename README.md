## 바뀐 것
1. **질문은행 입력 창 — 유형 '제시문'일 때** (선생님)
   - 칸: 학교* · 전형 · 주제* · 대상 학과 · 제시문* · 문항 1번·2번…(+ 문항 추가 · ↑↓ · ×, 최대 10개) · **숙독 시간*·답변 시간*(분)** · 질문 의도 · 꼬리질문
   - 학교·전형 칸은 이미 쓴 학교와 학생 지원 대학 이름을 골라 넣을 수 있어요. 같은 학교를 다르게 쓰지 않게 하려는 거예요.
   - **숙독·답변 시간은 기본값이 없어요.** 비우면 "숙독 시간과 답변 시간을 넣어 주세요"가 뜨고 저장되지 않아요. 학교·주제·제시문·문항이 비어도 마찬가지예요.
   - 답변 시간은 1번부터 마지막 문항까지 **모두 합친** 시간이에요.
   - **예전 제시문**(학교 없음)을 열면 `(1)` `1.` `1)` `①` 를 기준으로 1·2·3번 칸에 나눠 넣어 줘요. 시간 칸은 비워 둬요.
   - 제시문을 다른 유형으로 바꿔 저장하면 학교·주제·문항 칸은 지워요.
   - 다른 유형(학생부·인성·MMI)의 입력 창은 그대로예요.
2. **질문은행 목록**
   - 한 줄에 `[제시문] 가나대 · 학생부종합 (면접형) · 주제` 가 보이고, 아랫줄에 '문항 3개 · 숙독 10분 · 답변 7분 · 계열 · 학과', 그 밑에 문항 목록이 나와요.
   - 위에 **학교로 거르기**가 생겨요 (제시문이 있을 때만). 검색은 주제·학교·모든 문항까지 찾아요.
   - 예전 제시문에는 **'예전 양식 — 부스·연습에서 쓰지 않아요. 학교·주제·문항·시간을 넣어 다시 저장하거나 지워 주세요'** 가 떠요.
   - 학교는 있는데 빈 칸이 있는 제시문(예: AI로 만든 뒤 시간을 안 넣은 것)도 '빈 칸이 있어 부스·연습에서 쓰지 않아요'가 떠요.
   - **기본 질문 불러오기**에서 제시문 예시 4개를 뺐어요. 다시 눌러도 예전 양식 제시문이 들어오지 않아요. 이미 들어 있는 4개는 '예전 양식'으로 보이니, 고쳐 쓰거나 지워 주세요.
3. **학생에게 보내기**(선택한 질문을 학생에게 배정): 학교·전형·주제·문항 목록도 같이 복사해요.
4. **학생 혼자 연습** (제시문 · MMI → 제시문)
   - 학교·주제·문항·시간이 모두 있는 제시문만 나와요. 학생 홈 연습 카드와 '제시문 · MMI' 고르기 카드의 제시문 개수도 이것만 세요 (고르기 카드는 'n개').
   - **학교·전형 고르기**
     - 같은 학교·전형끼리 한 카드로 묶고 '아무거나' 카드도 있어요.
     - 내 지원 대학 카드는 맨 위에 '내 지원 대학' 표시가 붙고, 처음부터 골라져 있어요. 없으면 '아무거나'가 골라져 있어요.
     - 학교·전형이 하나뿐이면 고르는 칸 없이 안내만 보여요.
   - **문항 수·시간은 고르지 않아요.** 선생님이 정한 숙독·답변 시간 그대로예요.
   - **숙독**: 학교·전형·주제, 제시문, 문항 목록 1·2·3번, 메모 칸이 보여요. [다 읽었어요]를 누르거나 시간이 다 되면 1번으로 넘어가요.
   - **1번부터 한 문항씩**
     - 위에 '1번 ✓ 2번 3번' 단계 표시가 있어요.
     - 시계는 세트 전체 남은 답변 시간이에요. 문항이 바뀌어도 이어서 줄어요.
     - 면접관 음성은 "1번 문항입니다. …"예요.
   - **답변 시간이 다 되면** 그 자리에서 끊어요.
     - "시간이 다 돼서 여기까지 할게요."라고 말하고 화면에도 띄워요.
     - 남은 문항은 건너뛰어요. 말하던 답변은 거기까지 저장해요.
   - **마지막 문항까지 답했고 1분 넘게 남으면** 등록된 꼬리질문을 하나 해요. 꼬리질문도 남은 시간 안에서만 답해요. 연습 화면에는 AI 꼬리질문이 없어요.
   - **결과 화면**
     - 숙독 쓴 시간/정한 시간, 답변 쓴 시간/정한 시간, '문항 3개 중 n개 답변'이 보여요.
     - 시간 끝에 걸린 문항은 '시간 끝에서 끊김', 못 한 문항은 '시간이 다 돼서 못 했어요'로 보여요.
   - **기록**(sessions)은 부스와 같은 모양이에요.
     - 물은 문항마다 한 줄씩 남겨요: `type "passage"` · `pNo` · `pOf`.
     - 1번 줄에만 제시문·`prepSec`(숙독)·`prepUsedSec`·메모가 들어가요. `answerSec` 은 세트 답변 시간이에요.
     - 꼬리질문은 마지막 문항 줄에 들어가요.
     - 맨 위에 `passageSet { qid, univ, admission, topic, n, readSec, readUsedSec, answerSec, answerUsedSec, done, timeUp }` 를 남겨요.
   - MMI·다른 유형 연습은 그대로예요.

## 부스에 알릴 것
- `common.js` 에 **새 export 4개**가 생겼어요: `passageReady(q)` · `passageItems(q)` · `passageSchool(q)` · `PASSAGE_MAX_ITEMS`
  - 부스가 '쓸 수 있는 제시문'을 고를 때 같은 기준(학교·주제·제시문·문항 1개 이상·숙독·답변 시간)으로 쓸 수 있어요.
  - 기존 export 25개와 `TYPES`(제시문 600·420 그대로)는 바뀌지 않았어요.
- 질문은행 제시문 데이터는 요청서대로예요: `univ`·`admission`·`topic`·`items [{q}]`·`text`(=1번)·`prepSec`·`answerSec`(세트 합).
  - 숙독·답변 시간이 빈 제시문은 `prepSec`·`answerSec` 이 `null` 이에요.
- 혼자 연습 기록(mode `"passage"`)도 부스 기록과 같은 모양이에요: `items` 의 `pNo`·`pOf`·`passageSet`.
  - 연습 기록에는 부스에만 있는 칸(`interviewers`·`askedBy`·지표 등)은 없어요.
- 기본 질문에서 제시문 예시가 빠졌어요. 부스 시험은 이 사본으로 모두 통과했어요.
