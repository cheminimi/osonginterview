■ v4 수정 (t-students.js)
  1) 저장 응답을 기다리는 동안 더 쓴 내용이 지워지던 문제
     - 메모·학생 정보 칸마다 입력 버전을 매기고, 저장 요청 당시 버전과 같을 때만
       임시 입력 삭제 · '저장됨' 표시 · 폼 다시 그리기를 합니다.
     - 같은 내용 저장 중 중복 클릭은 무시, 새 저장은 앞 저장이 끝난 뒤 보냅니다(응답 순서 역전 방지).
     - 저장 중 표시 '저장 중…', 저장 뒤 더 고친 경우 '저장 안 됨 (저장 후 고친 내용)'.
  2) 폭을 1000px 아래로 줄일 때 다른 작성 창(면접 기록·면접일·연습 리뷰)을 덮어쓰던 문제
     - 다른 창이 떠 있으면 그대로 두고, 학생 상세는 그 창을 닫은 뒤에 되살립니다.
